# 人物参考 · ComfyUI 节点包（Character Reference）

**仓库地址：<https://github.com/winchao110/ComfyUI-CharacterReference>**

把「人物造型参考」做成四个可视化节点：**发型选择器** + **服装选择器** + **人脸选择器** + **其他素材管理节点**。
节点上直接显示当前选中的图，**点一下弹出选择面板**，选完自动写回节点，
执行时输出「图片 + 中文提示词」，可以直接接到 Qwen-Image-Edit / SDXL / 视频工作流里当参考图。

| 节点 | 菜单位置 | 图库 | 输出 |
|---|---|---|---|
| 发型选择器 | 人物参考 / 发型 | 82 款（女生 52 / 男生 30），640×640 | 发型图 + 中文提示词 |
| 服装选择器 | 人物参考 / 服装 | 1407 款（8 分类 × 女装 / 男装），800×1200 | 服装图 + 中文提示词 |
| 人脸选择器 | 人物参考 / 人脸 | 163 张中国人脸（女 123 / 男 40），768×768 | 人脸图 + 中文提示词 |
| 其他素材管理节点 | 人物参考 / 其他素材 | **初始为空**，由用户自己加 / 删，类别可自定义，尺寸不限 | 素材图（原尺寸）+ 提示词 |

> 目录名保持英文 `ComfyUI-CharacterReference`（ComfyUI 按目录名当模块名加载，中文目录会有兼容风险），
> 节点菜单里的分类名是「人物参考」。

**现成工作流**：`examples/` 里有两个 Qwen-Image 2.1 示例，直接拖进画布就能跑 ——
`qwen-image-2.1-character-text2img.json`（三选择器 → 文生全身图）、
`qwen-image-2.1-outfit-swap.json`（换装 / 换头 / 文生四条分支），
依赖的模型与第三方节点见 `examples/README.md`。

## 一、发型选择器

1. 新建节点 → **人物参考 / 发型 / 发型选择器**（或双击画布搜「发型选择器」）
2. 点节点上的缩略图（或「选择发型」按钮）→ 弹出面板
3. 切「女生 / 男生」，也可以直接搜（「大波浪」「寸头」「波波头」）
4. 点卡片即选中并关闭；「随机」按钮 = 抽一款；`random` 开关打开则每次执行都随机

**「＋ 添加发型」**：选图（浏览器先裁成 640×640）→ 填名称（必填）→ 选女生/男生 →
提示词选填（留空输出 `发型XX。`；填了自动拼成 `发型XX，你的描述。`）→ 保存后自动选中。

**「🗑 删除发型」**：进入删除模式，每卡右上出现复选框，勾选多个后点红色「删除选中 (N)」，
确认后连同图片一起删除；当前选中项被删会自动回退到同性别第一款。

输出：

| 输出口 | 类型 | 内容 |
|---|---|---|
| 发型图 | IMAGE | 方形发型图（边长由 `size` 决定，默认 640，与素材原图一致） |
| 提示词 | STRING | 如「发型长直发，柔顺笔直的长发，发丝顺滑垂落……」 |

参数：`hairstyle_id`（前端隐藏）、`size`（默认 640）、`random`。

## 二、服装选择器

1. 新建节点 → **人物参考 / 服装 / 服装选择器**
2. 点缩略图 → 弹出面板，**8 个分类按钮**：
   `全部 / 春装 / 夏装 / 秋装 / 冬装 / 内衣 / 派对 / 泳装 / 性感`
3. 上面还有「女装 / 男装」切换 + 搜索框（中文提示词、英文原描述、分类名都能搜）
4. 卡片 = **图片（2:3）+ 图下方的中文提示词**，点卡片即选中并写回节点

**「＋ 添加服装」**：只有两项必填/选填 ——
选图（浏览器先裁成 **800×1200**）+ 提示词（**选填**）；
另外记得选性别（女装/男装）和分类（默认跟随当前分类）。
留空提示词时该项只出图、提示词输出为空字符串，卡片上显示「（未填提示词）」。

**「🗑 删除服装」**：与发型一致（多选、确认、连图删除）。

输出：

| 输出口 | 类型 | 内容 |
|---|---|---|
| 服装图 | IMAGE | 默认 800×1200（由 `width` 决定，高 = 宽 × 1.5） |
| 提示词 | STRING | 如「服装：身穿黑色针织连衣裙，腿上穿黑色连裤袜，脚踩短靴。」 |

参数：`garment_id`（前端隐藏）、`width`（默认 800，范围 256–1600，偶数对齐）、`random`。

### 图库来源与中文提示词

服装图来自本机 PoseSwap 图库（原图 1366×2048 webp），构建时统一转成 **800×1200 JPEG** 存进节点包。
原始英文描述是扁平词组（如 `black knit denim midi skirt sandals mini bag silver necklace`），
`tools/build_garments.py` 用词表翻译后按穿搭顺序拼成中文：

```
颜色 → 图案 → 长度 → 材质 → 细节 + 品类
dress/top/bottom/legwear/shoe/bag/acc 依次写成
「身穿…，内搭…，下身穿…，腿上穿…，脚踩…，手拎…，搭配…」
```

例：`black leather mini skirt tights suede boots bag` →
`服装：下身穿黑色迷你皮革半身裙，腿上穿连裤袜，脚踩麂皮靴子，手拎手提包。`

全库 8 个分类的条数：春装 215、夏装 254、秋装 244、冬装 253、内衣 199、派对 48、泳装 54、性感 140。
**原库全是女装**，男装分类初始为空，等你自己在面板里上传（上传时性别选「男装」）。

## 三、人脸选择器

1. 新建节点 → **人物参考 / 人脸 / 人脸选择器**（或双击画布搜「人脸选择器」）
2. 点缩略图 → 弹出面板，顶部「女性 / 男性」切换
3. 卡片 = **面部 1:1 特写 + 图下的特征描述**，左上角标「女 / 男」
4. 搜索框支持特征词（「鹅蛋脸」「单眼皮」「清冷」）
5. 点卡片即选中并写回节点；「随机」按钮 = 抽一张；`random` 开关打开则每次执行都随机

**「＋ 添加人脸」**：选图（浏览器先裁成 768×768）→ 填面部特征（必填，格式「脸型，五官，气质」）→
选女性/男性 → 提示词**选填**。

提示词规则：

| 情形 | 输出 |
|---|---|
| 提示词留空 | `中国女性面部，鹅蛋脸，细眉杏眼，温柔恬静。`（自动拼） |
| 填了提示词 | **整句照用**，只补句号，不再加前缀 |

**「🗑 删除人脸」**：与发型 / 服装一致（多选、确认、连图删除）。

输出：

| 输出口 | 类型 | 内容 |
|---|---|---|
| 人脸图 | IMAGE | 方形人脸图（边长由 `size` 决定，默认 768） |
| 提示词 | STRING | 如「中国女性面部，长脸，挑眉深眼窝，冷艳英气。」 |

参数：`face_id`（前端隐藏）、`size`（默认 768）、`random`。

### 命名口径

文件名本身就是特征串，`001_长脸，挑眉深眼窝，冷艳英气.jpg` →
`name_cn = 长脸，挑眉深眼窝，冷艳英气`。三段分别是 **脸型 / 五官 / 气质**：

- 脸型：鹅蛋脸、圆脸、方脸、方圆脸、长脸、菱形脸、心形脸
- 五官：眉形 + 单/双眼皮 + 眼型 + 鼻唇（「浓眉深目」「单眼皮宽眼距」「细眉杏眼」）
- 气质：温婉端庄、清冷疏离、憨厚朴实、硬朗英气、儒雅学者……

## 四、其他素材管理节点

1. 新建节点 → **人物参考 / 其他素材 / 其他素材管理节点**
2. 库**初始为空**，点「＋ 添加素材」自己攒；卡片左上角标原始尺寸、左下角是**类别标签**
3. 添加时**只需要选图**：类别和提示词都可以不填；点了「✎」随时能改
4. 支持一次多选多张，每张单独一行提示词

**类别**：

- 类别栏可以**选已有类别**，也可以**直接填一个新的**——不用预先建分类，填什么就是什么
- 不填（或只填空格）**自动归到「其他」**
- 面板顶部有类别标签行：`全部 / 各分类`，带该类数量，点一下只看这一类，再点「全部」回来
- 某类的图全部删掉后，这个类别标签会自动消失
- 老数据没有类别字段，一律显示为「其他」

**画质口径**：

| 情形 | 处理 |
|---|---|
| 压缩栏**留空** | 原图**原样保存**：像素尺寸、文件字节都不动（实测下载回来与原图 MD5 一致） |
| 填 `2`（百万像素） | 按总像素等比缩放到 2MP，长宽比不变；只缩小、不放大 |
| 原图带 EXIF 旋转 | 自动摆正（这一种会重编码，JPEG q95 / PNG 无损） |

压缩单位是**百万像素（MP）**，等于 长 × 宽 ÷ 1,000,000，自由填小数（0.1 ~ 400）；
比如 4000×3000 是 12MP，填 `3` 就得到约 2000×1500。

输出：

| 输出口 | 类型 | 内容 |
|---|---|---|
| 素材图 | IMAGE | **原始像素尺寸**，不裁不缩（走 downstream 再按需 resize） |
| 提示词 | STRING | 填了就原样输出；没填则是空串 |

参数：`asset_id`（前端隐藏）、`random`。

**「🗑 删除素材」**：与其它三个面板一致（多选 → 确认 → 连图片文件一起删）。

## 六、重建图库

```bash
# 发型
python tools/build_library.py [女生图目录] [男生图目录] [提示词txt]

# 服装（默认读本机 PoseSwap 图库）
python tools/build_garments.py [garment.json] [图片目录]

# 人脸（源目录下要有 女/ 男/ 两个子文件夹，文件名「序号_脸型，五官，气质.jpg」）
python tools/build_faces.py "<人脸图库目录>"
```

发型 / 服装会**保留面板里手动添加的条目**（`"source": "user"` 的 `uNN`）；
人脸重建是整体替换（旧图已备份在 `custom_nodes/_backup_nodes/faces_old188_20261102/`）。

## 八、人脸素材来源

- `assets/faces/f001..f163.jpg`：**163 张 768×768 纯面部方形特写**（女 123 / 男 40），19 MB。
- `assets/faces.json`：`{id, gender, name_cn, prompt_zh, img, src}`，`prompt_zh` 形如
  `中国女性面部，长脸，挑眉深眼窝，冷艳英气。`
- **来源**：本机 360 + Bing 图片搜索抓取的真实照片（纪实／民生／职业类关键词），非合成脸、非图库模特。
  流程：关键词取图 → YuNet 人脸检测（单人、正脸、脸宽与清晰度阈值）→ 以眼睛定位按脸宽 ×1.14 裁 1:1 →
  CLIP 零样本剔除外国脸 / AI 渲染 / 妆造图 → **人工逐张筛选并按「脸型，五官，气质」命名**。
- **第二批（2026-11-02，24 张）**：`Downloads\人脸库\新建文件夹\ai-face-*.png`（1122×1402），
  同一套 YuNet 检测 + 1.14× 脸宽裁切，源目录编号 女 100–123，对应库内 **f100–f123**。
  与第一批口径不同：这批是 **AI 生成人像**（棚拍平光、皮肤高度平滑、几乎全为鹅蛋脸），
  YuNet 置信度普遍只有 0.58–0.86（真人照通常 >0.88），故该批的检测阈值单独放宽到 0.55 / 锐度 25。
  需要区分真人素材时按 `f100` 之后断开即可。
- 抓取、检测、裁切、导入脚本在 `tools/build_faces.py`（导入 + 建 json）与工作区 `_faces_crawl/`（抓取链路），
  原始素材与模型缓存已清理，模型（YuNet 232KB + genderage 1.3MB）留在 `_faces_crawl/models/`。

## 九、说明

- 图片仅作本地造型参考与提示词对照使用；商用请替换为自己拍摄或授权的素材。
- 改完 Python 代码需要重启 ComfyUI（Manager → 重启）生效；只改 `web/*.js` 的话浏览器强制刷新即可。
- 发型图建议 1:1，服装图建议 2:3，其他比例上传会自动居中裁剪。
- 「其他素材」节点不裁不压，任意比例都按原样保存与输出；只有填了压缩像素才等比缩放。
- 「其他素材」的类别是自由文本：先出现的排在前面，「其他」永远排在最后；类别名最长 24 字。
